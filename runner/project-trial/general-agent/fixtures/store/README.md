# store：一个小型电商后端

给 Agent 练手用的示例仓库。代码量不大，但结构和真实项目一样：金额、商品、库存、优惠、购物车、订单各管一摊，测试在 `tests/` 下。

```
store/
  money.py       金额：统一用“分”做整数运算，进出口才转成元
  catalog.py     商品目录
  inventory.py   库存：下单时先预占，支付后扣减，取消时释放
  coupons.py     优惠：会员折扣和满减券
  cart.py        购物车
  orders.py      下单：算钱、预占库存、生成订单
tests/           pytest 用例
```

## 业务规则

1. 金额保留到分，四舍五入（2.675 元记为 2.68 元）。
2. 优惠的顺序：先打会员折扣，再用满减券。满减券的门槛按**折扣后**的金额判断。
3. 一张订单最多用一张满减券，减完不低于 0。
4. 库存预占：可售数量 = 库存 - 已预占。可售数量不够时下单失败，已经预占的要全部释放。

## 运行测试

```bash
python -m pytest -q
```
